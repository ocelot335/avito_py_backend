make up - поднять инфру  
make down - остановить инфру  

make sentry-up - поднять sentry  
make sentry-down - остановить инфру  


make migrate - запустить миграции  
make api - запустить сервер  

make worker - запустить воркера для асинхронных задач  

если надо запустить несколько воркеров, то надо уточнить параметр N,  
например для запуска 3 воркеров надо писать:  
make worker N=5


make test-unit - запустить юнит-тесты  
make test-integration - запустить интеграционные тесты  
make test - запустить все тесты
